FREQUENTLY ASKED QUESTIONS

Clear answers. No vague AI hype.

How do you prevent hallucinations or catastrophic mistakes? +
Every agent we build has deterministic boundary policies and hard human approval gates. For routine actions (like looking up an order status), the agent executes autonomously. For destructive or sensitive actions (issuing a refund over $50, changing vendor bank details, emailing a VIP lead), the agent drafts the action and asks your human operator to approve with one click.
Where does the agent code run? Do you store our data? +
Agents run entirely within your own cloud environment, API keys, and workspace (AWS, GCP, Supabase, or Railway). We operate under strict mutual NDA and zero data retention. Your sensitive company data never touches our servers and is never used to train any public AI model.
What happens if an API changes or an underlying LLM updates? +
On the Run plan ($1,500/mo), we provide continuous telemetry, uptime monitoring, and prompt engineering updates whenever third-party APIs update or superior AI models release. If you choose not to subscribe to Run, we hand over 100% of the code, prompt logs, and regression test suites so your internal team can maintain it independently.
Why a fixed price of $6,000 instead of hourly agency billing? +
Hourly billing creates misaligned incentives where agencies benefit from moving slowly. We build one scoped, proven workflow at a fixed price agreed upfront. You know the exact launch date, the exact success metrics, and the exact ROI before writing a single check.
Can our internal developers take over the codebase? +
Yes, absolutely. You receive a complete Git repository with clean documentation, unit tests, and integration fixtures. We use clean, modern Python or TypeScript frameworks with zero proprietary lock-in.
